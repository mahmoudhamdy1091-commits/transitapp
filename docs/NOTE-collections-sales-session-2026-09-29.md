## قاعدة جديدة لازم تعرفوها
**سطور التحصيل الشاغلة (`isOccupying`) لأي فاتورة مجموعها = قيمة الفاتورة** (مدفوع + مستحق). أي كود بيضيف أو بيغيّر أو بيلغي سطر تحصيل مدفوع لازم يظبط المستحق بـ`adjustInvoiceDue`. المسارات اللي بتعمل ده دلوقتي: الفورمين، تعديل تحصيل، الرفض، الإلغاء، الحذف، رفض التعديل، `_processReversalApproval`، وتعديل فاتورة البيع. أما كاسكيد إلغاء أو حذف الفاتورة نفسها فمش محتاج.
